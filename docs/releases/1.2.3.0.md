# Version 1.2.3.0

- Added the TAE Republic V-wing with House Karr gold/dark-grey hull, wings and astromech textures. Replaced Republic markings with black House Karr emblems, oriented side emblems toward the cockpit, and removed yellow wing markings in favor of surrounding grey.
- Matched V-wing airbrake settings to the TAE Delta-7. Other flight-performance settings remain inherited from 3AS.
- Equipped the V-wing with the SOB/MTI AA cannon and two ammunition magazines. Added a mixed six-pylon loadout: Pursuit medium-range air-to-air missiles, Firebrand air-to-ground missiles and SOB/MTI three-bomb laser-guided SDB racks. Ground-attack pylons support either Firebrand or the bomb rack; these are not custom TAE SDBs.
- Repainted both TAE Acclamators with darker grey hull/landing gear, removed side stripes and Republic logos, and retained the central red panels. Engines, glass and interiors remain unchanged.
- Added Towi's Nite Owl armor and Bingo's Battle armor to Clan Acklay, the restricted arsenal, XTD selector and wearable loadout actions. Both armor textures are credited to Jimothy.
- Added Jimothy's JT-12 jetpack to the arsenal and custom backpack selector, credited to House Kandosii and Jimothy.
- Recorded a future TAE PK-V5 variant as planned work; no PK-V5 vehicle is added in this release. GCI remains excluded.

## Validation and Deployment

- Static config compilation and whitespace checks passed. Final wing-marking removal, pylon operation and new armor/jetpack integration still need in-game verification.
- Rebuild/sign using the normal workflow; this release publishes source and runtime textures to Git, not Workshop binaries.
- Editable reference textures and scratch editing scripts remain local under existing ignore rules.
