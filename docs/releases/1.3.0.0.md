# Version 1.3.0.0

- Added the OPFOR [TAE] Mining Guild faction from Havoc's composition: 20 distinct unit/vehicle classes and three infantry formations. Added TAEMiningGuild to all build scripts; source mod dependencies remain required.
- Added House Karr PX-10 CAV (R3) under Independent / House Karr / Speeders, with all attachments visible and their Garage hide options removed. Includes Edonn's grey/Rook textures, an 8K hull for side decals, corrected dozer crest orientation, and restored upstream inheritance so the original Imperial R3 remains intact.
- Added pilot-restricted aircraft requisition and standalone aircraft service pad modules with terminal scroll actions, configurable aircraft lists, progressive repair/refuel, timed rearm and compatible pylon changes.
- Added the OPTRE personal arsenal locker alongside the existing arsenal crate, using the same restricted arsenal setup.
- Added a Hang In There poster using a vanilla texture object, without a JMS dependency for the poster.
- Added a configurable local bridge-visibility module with interior-layer and exterior selection, a 3D zone and exclusions for independently controlled ray shields. Acclamator paint now uses House Karr gold accents.
- Changed House Link to use an opt-in Clan Leader addon setting, disabled by default. Added stacked downed-leader alerts above Clan Link for designated leaders; alerts are hidden in House Link view. Expanded vanilla weapon/grenade HUD suppression while retaining optic distance readouts.
- Standardized House Karr vehicle display names. Removed flaps from the Kom'rk, Z-98 and Delta-7, and removed Kom'rk airborne passenger recovery.
- Updated V-wing countermeasures to match the Delta-7 and expanded its radar coverage to 360 degrees horizontally and vertically.
- Updated Delta-7 with four Talon short-range air-to-air racks, no bomb loadout, 20% lower hull armor and a TAE cannon based on SOB with lead/impact indicators (4+8).
- Added server-mediated BARC stretcher deployment/stow handling for multiplayer and restored New Republic aircraft parent inheritance.
- Updated confirmed author credits across helmets, vehicles, flags, insignias, vexilla, furniture, crates, droids, drone equipment and DEFIB. Included author-audit snapshots and asset tooling.

## Mission Compatibility

- Replaced TAE_Unit_Player_Acklay with TAE_Unit_Player_Mandalorian_LS and TAE_Unit_Player_Foxx with TAE_Unit_Player_Mandalorian_TGF.
- Removed the Kyram, Haranverd, Rook, Varen and Freelancer player-unit classes. Foundling and Shyyyo units remain. Existing missions using removed classnames require manual updates.
- The new locker requires OPTRE_BW_Locker; Mining Guild requires the source composition's addon dependencies.

## Validation and Deployment

- Static config compilation, importer tests and Git whitespace checks performed for this release. These do not validate merged in-game inheritance or multiplayer behavior.
- PX-10 Eden visibility and rebuilt textures, new modules, BARC multiplayer behavior and HUD integration still require in-game confirmation. The 8K hull increases texture memory use; original panel detail remains 2K-derived.
- Source release only: rebuild/sign using the normal workflow before Workshop/server deployment. No deployment is implied by merging main.
- GCI remains excluded/on hold. Ignored reference texture folders and scratch files remain local; tracked flag and jetpack references are retained.
