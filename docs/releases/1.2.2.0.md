# Version 1.2.2.0

- Added the compact Join TAE Server main-menu tile. Removed vanilla spotlight tiles and backdrop, and resolved 3AS/LS menu load-order conflicts.
- Added the House Karr BARC speeder with stretcher functionality, custom grey/gold texture, doubled repeater fire rate, 180 km/h maximum speed, suspension/steering adjustments and high-speed engine audio.
- Added KND Womprat tripod, gun and battery to the restricted arsenal and CSW Quartermaster description.
- Added Delta-7 "Ashwing" with custom purple/dark-red livery, adjusted thrust and altitude performance, pitch-drift correction, cannon/laser-only armament and expanded radar coverage.
- Expanded Z-98 and Delta-7 radar coverage to 360 degrees horizontally and vertically, with increased sensitivity to low-signature targets.
- Updated Talon, Pursuit and Longspear missiles with combined IR/radar guidance and lock-range adjustments. Talon has increased maneuverability; Pursuit has increased thrust; Longspear has a 12 km lock limit and 8000 km/h configured maximum speed.
- Added independent map, camera and motion-tracker placement settings; Clan Link and House Link; icon-based fire modes; and HUD visibility/layout fixes. Removed the speed readout above the map.
- Fixed Galaar-90a targeting-scope inheritance and included accumulated weapon/helmet configuration updates.
- Added standard and landed TAE Acclamators with optional Sci-Fi Support Plus FTL registration. Further in-game/MP testing is deferred.
- Updated confirmed custom armor/helmet author credits and included contributor texture assets from dev.
- Standardized texture naming and included flag/jetpack reference textures. Other ignored reference folders remain local.
- Included the LS MPL compatibility update: Nihil grenadiers retain 30 rounds using the current single-round G76 HEF magazines.
- Retired the temporary Tatooine grid workaround following the upstream fix.

## Deployment

- Remove any old `tae_tatooine_grid_fix.pbo` and matching signature from existing release/server folders; rebuilding does not remove obsolete files automatically.
- Rebuild and sign the mod using the normal build workflow. This Git release does not build or upload Workshop binaries.
- BARC and Womprat were confirmed working by the user. Latest menu sizing and other unconfirmed changes still need in-game verification.
- GCI remains excluded.
